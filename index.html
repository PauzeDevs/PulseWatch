Website monitoring, made understandable

Know when your website is up.

PulseWatch is a lightweight website monitoring project focused on availability checks, response-time visibility, and a readable history of service incidents.

Explore the projectExplore features

Check a website instantly

Enter a public HTTPS address to verify its DNS and test its HTTPS connection. Results appear here without adding it to the monitor list.

Quick checks are one-time browser tests, not continuous monitoring. Some sites hide HTTP status codes from browsers through CORS; PulseWatch will show that limitation rather than guess.

Clear visibility into website health

The project is being designed around the essential signals that help developers understand whether a website is reachable and how it is responding.

Uptime checks

Check whether a monitored website responds successfully and identify availability interruptions.

Response-time tracking

Record request duration to help reveal slow responses and performance changes over time.

Incident history

Keep a chronological record of detected outages and recoveries for easier troubleshooting.

Built for a lightweight workflow

PulseWatch checks a curated list of public websites on a five-minute schedule using GitHub Actions. Community members can request additional sites for review through the Add a website page.

Monitoring is best-effort and is not an uptime SLA. Community-submitted websites are reviewed before they are added. Check history begins when monitoring starts; past uptime is not inferred.
