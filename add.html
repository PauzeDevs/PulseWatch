Community monitor requests

Put a website on the radar.

Suggest a public website for PulseWatch to monitor. Requests go to GitHub for review; approved sites are added to the scheduled checks and appear on the public dashboard.

Requests are reviewed by the PulseWatch maintainers before monitoring begins. Do not submit private dashboards, internal network addresses, login-only pages, or URLs containing passwords, API keys, or other secrets.

GitHub account sign-in may be required to submit the request. Submitting a request does not guarantee acceptance.
